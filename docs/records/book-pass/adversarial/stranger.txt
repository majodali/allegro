(a): "assumed" is used before D21 defines it.
- D19 "Host code reaches a program only as primitive functions" — (a): "composed function" appears here and is defined only at D38.
- D23 "Each decision lives in one replaceable unit of code" — (a): "unit" is never defined in the file. The only explanation, "the smallest units that each hold one decision", is circular.
