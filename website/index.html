Allegro

A programmable language platform built on partial evaluation.

Allegro is a minimal, flexible core language designed for human-AI collaboration. It provides familiar syntax, a rich type system, and extensible semantics — all built from a small set of primitives and the principle that partial evaluation is compilation.

Allegro is a work in progress. The examples below are live — edit them and click Run to experiment. Open the full sandbox for a richer experience.

Types

Every value in Allegro Standard has a type. Types enable dot-access dispatch, type checking, and compile-time inference. Built-in types include Int, Float, String, Bool, Array, and Object.
