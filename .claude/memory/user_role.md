The user (majodali) is the language designer and architect of Allegro. They think deeply about formal semantics, type system design, and the interaction between partial evaluation and type safety. They care about:

- Sound formal architecture built up from primitives
- Supporting variant implementations at every level (syntax, semantics, module systems)
- Human-AI collaboration as a core design goal
- Build/execution context as successive partial evaluation phases
- Keeping the base language minimal — extensions are where the language lives

They prefer to discuss design thoroughly before implementation, but are comfortable delegating implementation details. They want to understand trade-offs and edge cases. They think in terms of long-term architecture (Allegro Low/Mid/High variants) while being practical about what to build now.
